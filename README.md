EMERGENCE ENGINE 
Inspired by Conway's Game of Life, the emergence engine stands as a cellular simulation that displays simple molecular interactions.

For general use compile automaton.cpp and mapgen.cpp for Automaton and map generation. 
Once mapgen is compiled and has been ran to generate text maps, run automaton executable and watch the Agents go.  

Agents are defined by their charge (either + or -) while the ground landmarks are labeled by '*'. 
Further world implementations are in the works
